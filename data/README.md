# 采集数据

原始目录：`F:/BaiduNetdiskDownload/csi/`。
已保留相对目录结构复制 29 个 `.csi` 文件，合计 373,652,390 字节。
原始文件保持不变；`.csi` 被 Git 忽略。`manifest.csv` 记录路径、大小和 SHA-256，可核对拷贝。

`labels.csv` 是待填写的时间段标签模板，所有标签初始未知，不会根据目录名自动认定整段有人/无人。

- `file`：相对于 data 的路径，统一 `/`。
- `start_s,end_s`：以该文件首个有效系统时间戳为零点，左闭右开。
- `label`：0 无人、1 有人；空值表示未知。
- `split`：`calibration` 或 `test`；同一个文件不能跨两组。
- `notes`：人数、动作、姿态、门窗状态、环境干扰等采集说明。

一个文件可填多行；只给完全落入已知状态区间的窗口标注。
排除开门、上下车等过渡段，不要用检测分数反过来生成真实标签。
